The hidden risk: coordination cost grows faster than capability. Two agents aren't 2× better — often 1.5× better at 3× the cost and 5× the debugging. Split only when context forces you to.

✅ Split when

  • Context isolation is the goal
  • Genuinely different tools
  • Independent parallel subtasks
  • Adversarial separation needed
  • Distinct permission levels

❌ Don't split when

  • One agent + good prompt works
  • Boundaries are undefined
  • Latency matters
  • Cost is constrained
  • One coherent voice needed
  • No per-agent tracing

📐 The decision rule

Does one agent's context overflow?
├─ No  → Use ONE agent. Better prompt, better tools.
└─ Yes → Does the task split into independent subtasks?
         ├─ No  → ONE agent + a summarization step.
         └─ Yes → Multi-agent is justified.
